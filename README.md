# CHAuto - CH9329 Serial Mouse Controller

> A hardware-level automation controller based on CH9329 chip for serial mouse simulation

一款基于CH9329芯片的硬件级自动化控制工具，专为解决内网设备、无adb环境下的自动化操作需求而设计。通过串口连接CH9329设备模拟真实鼠标操作，无需root、无需安装客户端软件，即可实现精准的自动化脚本执行与图片预览控制。

## 简介

CHAuto 是一款专为内网/隔离环境设计的硬件鼠标自动化工具。通过 CH9329 串口芯片模拟真实鼠标操作，解决无法使用 adb 或安装客户端软件的场景下的自动化需求。支持自定义脚本编写、多节点流程编排、图片预览，适用于手机、平板等设备的自动化操作场景。

## 功能特性

- **串口控制** - 自动扫描并连接CH9329/CH340设备，支持连接/断开管理
- **脚本执行** - 自定义鼠标操作脚本，支持坐标定位、按键点击（左键/右键/双击）、延时等待
- **自动化配置** - 支持多节点流程编排：脚本执行、延时等待、图片切换/跳转，可循环执行
- **图片预览** - 支持PNG/JPG/BMP/GIF格式图片浏览，带抖动显示效果
- **运行日志** - 实时记录串口状态、脚本执行、自动化进度及错误信息
- **完全离线** - 不依赖网络和adb，适用于内网、隔离环境

## 硬件要求

**CH9329 + CH340 串口数据线**

- 这是本工具的必需硬件，用于通过串口连接电脑和目标设备
- 在拼多多等电商平台搜索"CH9329 CH340 串口线"即可找到
- 参考价格：**约 15 元**

> 注意：请购买 **CH9329 + CH340 二合一** 的线材，单独购买 CH9329 可能不包含 CH340 USB 转串口芯片驱动

- Python 3.12+
- 操作系统：Windows / Linux / macOS

## 适用场景

- **内网手机/平板** - 无法通过adb连接，无法安装客户端软件的自动化操作（支持OTG）

- **硬件自动化** - 基于真实鼠标模拟，无需系统权限，兼容性广泛

1. 点击「选择文件夹」
2. 选择包含图片的文件夹

### 执行脚本

1. 选择或新建脚本
2. 点击「执行当前」

### 运行自动化

1. 选择或创建配置
2. 点击「开始自动化」
3. 点击「停止」结束

## 脚本编写

### 语法格式

每条指令为一个四元组，格式如下：

```
(x, y, key, delay_ms)
```

其中：

| 参数 | 说明 | 取值 |
|------|------|------|
| x | 目标X坐标 | 正整数 |
| y | 目标Y坐标 | 正整数 |
| key | 按键类型 | 0=无(仅移动), 1=左键, 2=右键, 3=双击 |
| delay_ms | 执行后延迟 | 正整数（毫秒） |

### 示例

```txt
# 扫码脚本示例
(150, 200, 1, 500)   # 移动到二维码位置，左键点击，等待500ms
(0, 0, 0, 2000)      # 等待2秒
(400, 300, 1, 500)   # 点击确认按钮
```

### 执行流程

鼠标归位原点 → 移动到目标X坐标 → 移动到目标Y坐标 → 固定等待500ms → 执行点击操作（如有） → 等待指定的延迟时间

## 自动化配置

### 节点类型

| 类型 | 说明 | 参数 |
|------|------|------|
| 脚本 | 执行鼠标操作脚本 | 脚本名称、内容、执行后延迟 |
| 延时 | 固定等待 | 延时毫秒数 |
| 图片切换 | 切换到上一张/下一张 | 方向（next/prev） |
| 图片跳转 | 跳转到指定图片 | 图片索引 |

### 配置示例

```json
{
  "name": "扫码流程",
  "nodes": [
    {"type": "script", "name": "扫描二维码", "content": "(100,200,1,500)", "delay_after_ms": 500},
    {"type": "delay", "duration_ms": 2000},
    {"type": "image_switch", "direction": "next"},
    {"type": "delay", "duration_ms": 1000}
  ],
  "image_display": {"shake_amplitude": 10, "shake_speed": 0.2},
  "loop": {"enabled": true, "count": 0}
}
```

## 常见问题

**Q1: 串口连接失败**
- 可能原因：串口被占用、设备不存在、CH340驱动未安装
- 解决方案：关闭其他占用串口的程序、重新插拔USB、安装CH340驱动

**Q2: 脚本执行无反应**
- 可能原因：串口未连接、脚本格式错误、CH9329设备未正确连接
- 解决方案：检查串口连接状态、查看日志错误信息、检查设备连接

**Q3: 图片无法显示**
- 可能原因：文件夹无图片、格式不支持、文件损坏
- 解决方案：使用支持的格式（PNG/JPG/BMP/GIF）、检查文件完整性

**Q4: 自动化无法循环**
- 可能原因：循环未启用、已达到设定次数
- 解决方案：在配置编辑器中启用循环、设置循环次数为0（无限循环）
